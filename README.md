# 🤖 LLM & Hugging Face – Generative AI and Pretrained Models

## 📌 Overview
This repository focuses on exploring and implementing **Large Language Models (LLMs), Generative AI, and pretrained models** using various AI platforms and APIs.

### 🚀 Key Implementations
- **LLM Integration & Prompt Engineering:** Implemented various LLMs using Google AI Studio, Groq, and OpenAI APIs. Explored prompt engineering, Chain-of-Thought prompting, conversational memory, context management, and multi-turn interactions to develop AI-powered applications.

- **Hugging Face & Pretrained Models:** Explored and implemented pretrained models for various AI tasks, including Image Classification, Text Classification, and Text-to-Speech using the Hugging Face ecosystem. Experimented with model selection based on parameter count, download popularity, task capabilities, and supported input formats.

- PyTorch
