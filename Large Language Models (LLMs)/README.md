# Large Language Models (LLMs) – API Integration & Generative AI

## Project Overview
A hands-on implementation of **Large Language Models (LLMs)** using multiple API providers, including **Google AI Studio, Groq, and OpenAI**. This project explores API integration, prompt engineering, Chain-of-Thought prompting, conversational memory, and context-aware response generation using Python.

## Key Implementations
- **Google AI Studio Integration:** Integrated Google's generative AI models using API keys to perform text generation and interact with LLMs.
- **Groq API Integration:** Utilized Groq's high-speed inference platform to interact with supported open-source language models.
- **OpenAI API Integration:** Implemented LLM interactions using OpenAI API clients and explored different model capabilities and response generation techniques.
- **LLM Client Configuration:** Worked with different API clients, authentication using API keys, model selection, and API endpoint configuration.
- **Prompt Engineering:** Designed structured prompts using role-based instructions, contextual information, and specific output requirements to generate relevant and accurate responses.
- **Chain-of-Thought (CoT) Prompting:** Explored structured prompting techniques to encourage LLMs to break down complex problems into logical intermediate steps and generate step-by-step responses.
- **Conversational History Management:** Implemented conversation history to maintain context across multiple user interactions, enabling continuous and context-aware communication with LLMs.
- **Context-Aware Response Generation:** Incorporated previous user queries and AI-generated responses into subsequent prompts to maintain conversational continuity.
- **Response Generation & Handling:** Explored text generation across different LLM providers, response extraction, and comparison of model behaviour.
- **API Error Handling:** Practiced troubleshooting common API issues, including authentication errors, invalid model configurations, and endpoint-related errors.

## Technologies & Tools
- **Programming Language:** Python
- **LLM Providers:** OpenAI, Groq, Google AI Studio
- **Libraries:** OpenAI Python SDK, Groq Python SDK, Google Generative AI SDK
- **Concepts:** Generative AI, LLMs, Prompt Engineering, Chain-of-Thought Prompting, Conversational Memory, Context Management
- **Development Environment:** Google Colab

## Key Learning Outcomes
- Gained practical experience integrating multiple LLM providers through API clients.
- Developed an understanding of prompt engineering and structured prompting techniques.
- Explored Chain-of-Thought prompting for complex problem-solving tasks.
- Implemented conversational history management for context-aware interactions.
- Understood API authentication, model configuration, and response handling.
- Explored the capabilities and differences of various LLM providers.

## Project Objective
To gain practical experience with different LLM providers, understand their API integration workflows, and build a strong foundation for developing conversational AI applications and Generative AI solutions.
